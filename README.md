# Revolution of Arcade

A playable arcade experience that lets players explore an interactive arcade space and step into classic-inspired mini games.  
The project highlights the evolution of ball-based arcade games through playable experiences such as **Pong**, **Ping Pong**, and **Tennis for Two**.

## About the Project

**The Arcade** is a game project built around the idea of exploring an arcade store and playing different machines inside it.  
Players can walk through the arcade environment, collect coins, interact with cabinets, and enter mini games that represent different stages in the development of classic ball games.

The experience combines:
- Arcade store exploration
- Arcade machine interaction
- Coin system
- RenderTexture-based in-machine display
- Multiple playable mini games
- Score tracking
- Ending pages for each mini game
- Sound effects and arcade atmosphere
- Credits page for project assets

The goal of the project is to create a nostalgic arcade experience while showing how simple game mechanics can evolve across time through presentation, interaction, and technology.

---

## Features

- Explore a stylized arcade store
- Insert coins and activate arcade machines
- Play three mini games:
  - Pong
  - Ping Pong
  - Tennis for Two
- Smooth transition from arcade environment into gameplay
- In-machine gameplay displayed through RenderTexture screens
- Score tracking and result screens
- Audio feedback and arcade ambience

---

## Gameplay Loop

1. Start from the Main Menu
2. Enter the arcade store
3. Buy or collect coins
4. Approach and interact with arcade machines
5. Zoom into a playable mini game
6. Complete the game session
7. Return to the arcade and try another machine
